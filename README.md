# Bobby Carrot Level Generator

> [!NOTE]  
> Игра доступна по адресу https://name-organization.github.io/bobby-carrot-level-generator/

Проект представляет из себя кросс-платформенную реализацию игры Bobby Carrot с дополнительным функционалом:
- генерация уровней различной сложности и размеров
- навигация по уровням, основанная на SAT-решателе
- экспорт/импорт сгенерированных уровней
- улучшенный пользовательский интерфейс

Программный стек:
- Игра написана на C++, компилируется в WASM (WebAssembly) с помощью `Emscripten`.
- Библиотеки: `SDL2` (графика), `CaDiCaL` (SAT-решатель)
- Для сборки используется `Docker`

## Сборка

Проверено на WSL2, Ubuntu 24.04, Fedora, Mac OS.
Для сборки проекта нужен `Docker`, `Docker Compose`, `make`.

Чтобы собрать и запустить проект:
```bash
$ make run
```
Эта команда скачивает зависимости: SDL2, игровые ассеты (текстуры, звуки).

В случае проблем с командой `make run` (ненулевой код выхода с какой-нибудь ошибкой) стоит попробовать собрать вручную:
```bash
# Сборка
wget -O docker/sdl-release-2.32.10.zip https://github.com/libsdl-org/SDL/archive/release-2.32.10.zip
tools/fetch_assets.sh
docker compose build bobby
# Запуск игры в контейнере
docker compose up
```

По умолчанию игра запускается на порту `8080`, это можно изменить в `docker-compose.yaml`.

## Как играть

1. Откройте https://name-organization.github.io/bobby-carrot-level-generator/ (`localhost:8080`, если собираете вручную).
2. Выберите уровень:
  - **Generate level** создаёт новый уровень: нажмите на **Random seed**, или через
    **Enter seed** введите значение сида (`1 … 4294967295`), чтобы получить уровень, соответствующий этому сиду;
  - **Select level** открывает меню с выбором оригинальных уровней игры. Уровни открываются один за другим, 
  прогресс сохраняется в браузере (local storage).
3. Соберите все морковки (в уровнях с яйцами нужно пройти все клетки с травой). Счётчик в правом верхнем углу показывает, сколько морковок осталось.
4. Перемещайтесь с помощью стрелочек или клавиш <kbd>W</kbd> <kbd>A</kbd> <kbd>S</kbd> <kbd>D</kbd>; на телефоне стрелочки на экране.
5. Застряли? Нажмите на клавишу <kbd>H</kbd> (hint), чтобы увидеть путь до финиша.
6. При нажатии <kbd>H</kbd> экран покраснел? Уровень не может быть пройден до конца: нажмите <kbd>R</kbd>, чтобы начать уровень заново.
7. После сбора всех морковок, доберитесь до мигающего финиша.
8. Следующий уровень стартует автоматически.
9. Нажмите <kbd>Q</kbd> для выхода в главное меню.
10. **Settings** в главном меню позволяют настраивать громкость звуков и музыки.

Фоновая музыка -- оригинальная тема из игры.

На стартовой странице, в разделах «Настройки» и «Новый уровень» кнопки выбираются с помощью <kbd>↑</kbd> <kbd>↓</kbd> или наведения указателя мыши и подтверждаются клавишей <kbd>Enter</kbd> или ЛКМ; <kbd>Esc</kbd> возвращает назад. Доступные клавиши для текущей страницы перечислены под полем игры; их можно нажимать на клавиатуре или с помощью мыши. Все клавиши:

| Клавиша | Действие |
|---|---|
| &nbsp;&nbsp;&nbsp;&nbsp; <kbd>↑</kbd> <br> <kbd>←</kbd> <kbd>↓</kbd>  <kbd>→</kbd> | перемещение по полю / выбор |
| &nbsp;&nbsp;&nbsp;&nbsp; <kbd>W</kbd> <br> <kbd>A</kbd> <kbd>S</kbd> <kbd>D</kbd> | перемещение по полю |
| <kbd>Enter</kbd> | подтвердить |
| <kbd>H</kbd> | показать / скрыть подсказку |
| <kbd>R</kbd> | перезапустить уровень |
| <kbd>G</kbd> | сгенерировать новый уровень |
| <kbd>E</kbd> | скопировать ссылку на сгенерированный уровень |
| <kbd>Esc</kbd> | вернуться к предыдущей странице; из страницы со списком оригинальных уровней: вернуться в главное меню |
| <kbd>Q</kbd> | перейти в главное меню |
| <kbd>F</kbd> | приблизить / отдалить |
| <kbd>M</kbd> | включить / выключить звук |
| <kbd>V</kbd> | открыть настройки звука (приостанавливает уровень) |
