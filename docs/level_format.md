# Формат уровня `.lvl`

Уровень — текстовый файл: каждая строка файла — ряд карты, каждый символ — клетка.

Оригинальные уровни имеют размер 16×16 и лежат в `assets/v1/level/`: `normal01.lvl` … `normal30.lvl` (морковки) и `egg01.lvl` … `egg20.lvl` (трава). Их скачивает `tools/fetch_assets.sh` и конвертирует из оригинального формата `.blm` скриптом `tools/blm2lvl.py`.

## Пример

```
; Example
################
#0  *    *    a#
################
```

Уровень 16×3 с названием `Example`: старт, две морковки и выход в коридоре, окружённом живой изгородью.

## Разбор файла

Код: `Level::loadFromText` в `src/core/level.cpp`.

- Строка, которая начинается с `;`, — комментарий. Первый непустой комментарий — название уровня (без `;` и пробелов по краям).
- Каждая остальная строка — ряд карты, сверху вниз. Пустая строка — ряд из дорожки.
- Перевод строки в конце файла нового ряда не добавляет.
- Окончания строк — LF или CRLF.
- Высота уровня — число рядов, ширина — длина самого длинного ряда. Ряд короче дополняется справа дорожкой, поэтому пробелы в конце строки можно не сохранять.
- Максимум — 32 ряда по 32 символа.

Разбор завершается ошибкой, если:

- в файле нет ни одного непустого ряда;
- рядов больше 32;
- в строке больше 32 символов — сообщение указывает номер строки;
- встречается неизвестный символ — сообщение указывает номер строки и столбца.

Строки и столбцы нумеруются с 1, комментарии тоже считаются.

## Цель уровня

- Если на карте есть хотя бы одна морковка `*`, нужно собрать все морковки.
- Иначе нужно пройти по всей траве `X`.

Когда цель выполнена, открывается выход. Цель определяется содержимым карты, а не именем файла.

На карте должны быть ровно один старт `0` и один выход `a`. Загрузчик это не проверяет.

## Символы

Таблица соответствует `kTileChars` и `kTileAliases` в `src/core/tilechar.hpp`.

| Символ | Клетка |
|---|---|
| `#` `1`–`9` `(` `)` | живая изгородь, непроходима |
| `=` `"` `{` `}` `[` `]` | забор, непроходим |
| пробел, `.`, `C` | дорожка |
| `0` | старт; в остальном — дорожка |
| `a`, `@` | выход; уровень пройден, когда Бобби входит в него после выполнения цели |
| `*` | морковка; собирается, когда Бобби входит в клетку |
| `X` | трава; когда Бобби уходит с неё, превращается в `x` и, если на карте нет морковок, засчитывается |
| `x` | вытоптанная трава, непроходима |
| `_` | шипы, ещё не сработавшие; когда Бобби уходит с них, превращаются в `W` |
| `W` | сработавшие шипы; шаг на них убивает Бобби |
| `K` / `G` | серый ключ / серый замок |
| `Y` / `H` | жёлтый ключ / жёлтый замок |
| `R` / `D` | красный ключ / красный замок |
| `-` `\|` | рельс, горизонтальный / вертикальный; проходим только вдоль себя; когда Бобби уходит с него, поворачивается на 90° |
| `F` `T` `J` `L` | угол рельса, соединяет стороны восток–юг, запад–юг, запад–север, север–восток; войти и выйти можно только через эти стороны; когда Бобби уходит с него, поворачивается на 90° по часовой стрелке (`F` → `T` → `J` → `L` → `F`) |
| `b` / `B` | красная кнопка, активная / нажатая; шаг на `b` поворачивает все рельсы и углы рельсов (так же, как при уходе с них) и меняет все `b` на `B`, а `B` на `b` |
| `n` / `N` | жёлтая кнопка, активная / нажатая; шаг на `n` разворачивает все конвейеры и меняет все `n` на `N`, а `N` на `n` |
| `<` `>` `^` `V` | конвейер; войти на него и сойти с него можно только в его направлении; на конвейере Бобби сам делает шаг в его направлении |

Ключи подбираются, когда Бобби входит в клетку, и копятся. Войти в замок можно, только имея ключ того же цвета: ключ тратится, замок становится дорожкой.

`.`, `C` и `@` — синонимы: при сохранении уровня они записываются как пробел, пробел и `a`.

`o` (взятая морковка, появляется только во время игры) и `?` (не используется) — служебные символы. Загрузчик их принимает, но в уровнях их нет.
